# Greenhouse Helper iOS Skeleton

This folder contains the SwiftUI source scaffold for the hybrid iOS app.

Suggested next step in Xcode:

1. Create a new iOS App project named `GreenhouseHelper`
2. Copy these source files into the project
3. Add the Bloomlogic leaf logo to `Assets.xcassets`
4. Set the backend base URL in `AppSettings`

Expected backend:

- `POST /analyze-tray`
- `GET /health`

The app assumes the backend is reachable over local Wi-Fi, for example:

`http://192.168.1.10:8000`
